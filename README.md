# My Awesome App

A simple Python Flask application for testing security scanning.

## Features

- RESTful API
- Health check endpoint
- Containerized with Docker

## Running Locally

```bash
pip install -r requirements.txt
python src/app.py
```

## Running with Docker

```bash
docker build -t my-awesome-app .
docker run -p 5000:5000 my-awesome-app
```
